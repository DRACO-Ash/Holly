# can be read. The platform scores new code against the previous UPLOAD, passed or failed, and
# records that boundary nowhere in this repository (appstore-gate-compliance, section 2.3).
# Append one line per upload, in the first commit after it is handed over; never edit or remove a

#   upload <full 40-hex id of the commit packaged> <__version__ there> <passed|failed|pending> [# note]

# 8 hex digits of its SHA-256, the merge request and the stage that failed. Packaging for upload
# refuses unless the record is committed and its last line reads, and prints the files the upload
# changes since that baseline (scripts/check-baseline.sh). Printable ASCII and tabs only. The
# file sits outside the upload.
